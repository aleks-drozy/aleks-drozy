## Focus

- Quantitative research engineering: backtesting, walk-forward analysis, bootstrap statistics, and pre-registered experiments
- Full-stack product development with React, Next.js, Node.js, Express, and MongoDB
- Research integrity as a software problem: leak-free validation, regression locks, and honest reporting of null results
